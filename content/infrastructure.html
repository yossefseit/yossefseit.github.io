02 / Personal Azure networking lab

Secure Azure Hub-and-Spoke.

Lab: CI validated; Azure deployment pending. A private-by-default Bicep design with three VNets, explicit peering, isolated spokes and Blob access through Private Link.

Address plan

Three trust zones

Hub 10.0.0.0/16, app 10.10.0.0/16 and data 10.20.0.0/16, with NSGs, ASGs and cross-spoke blackhole routes.

Private service path

Endpoint and DNS together

The Blob private endpoint sits in the app spoke. The private DNS zone links to the hub and app only; public network access is disabled.

Optional validation

Compute stays off

The private test VM and VNet flow logs default to disabled. A live connectivity and isolation run remains pending.

03 / Personal Azure governance lab

Guardrails with a deliberate lifecycle.

Lab: CI validated; Azure deployment pending. Subscription-scoped Bicep for audit-first policy, bounded access, cost notifications and a protected governance resource group.

Policy

Audit before enforcement

Three custom definitions form one initiative. Required resource-group tags and allowed locations default to Audit; tag inheritance starts Disabled.

Cost signal

Actual and forecast alerts

A subscription budget routes notifications to an action group. The example deliberately contains no personal receiver.

Lifecycle

Ownership before cleanup

Scripts check subscription context, review what-if, require exact confirmation and use a manifest to guard deletion.
